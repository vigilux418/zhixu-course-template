一瞬间的变化率

仪表盘上的车速，是“这一瞬间”的速度。可一瞬间既没有路程，也没有时间，速度从何谈起？答案是：取平均速度的极限。

  • 把导数理解为差商的极限
  • 从定义出发求简单函数的导数
  • 使用求导法则与链式法则

从割线到切线

在曲线 y = f(x) 上取两点 (a, f(a)) 与 (a + h, f(a + h))，过这两点的割线斜率叫差商。让 h 趋于 0，割线就转向切线（）。差商的极限如果存在，就叫 f 在 a 处的导数：

f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}

这里的“趋于”就是上一讲定义的极限（）。导数除了记作 f'(x)，也常写成 \dfrac{\mathrm{d}y}{\mathrm{d}x}前一种记号来自拉格朗日，后一种来自莱布尼茨：它提醒我们，导数是两个增量之比的极限。。

如果 s(t) 表示时刻 t 走过的路程，差商就是一段时间内的平均速度，导数 s'(t) 就是瞬时速度。并非所有函数都处处可导：y = |x| 在 x = 0 处，差商的两个单侧极限分别是 -1 和 1，极限不存在，图像在那里是一个尖角。

从定义出发，求 f(x) = x^2 的导数。

解答
\begin{aligned} f'(x) &= \lim_{h \to 0} \frac{(x + h)^2 - x^2}{h} \\ &= \lim_{h \to 0} \frac{2xh + h^2}{h} \\ &= \lim_{h \to 0}\,(2x + h) = 2x. \end{aligned}

所以在 x = 1 处，切线的斜率是 2，与一致。

求导法则

每次都回到定义太慢。常用函数的导数列在里，可以直接使用。

基本初等函数的导数
f(x)f'(x)说明
c0常数没有变化
x^nn x^{n-1}幂法则
\sqrt{x}\dfrac{1}{2\sqrt{x}}幂法则取 n = \frac{1}{2}
\sin x\cos x推导要用

\ln x\dfrac{1}{x}要求 x \gt 0

函数经过四则运算与复合之后，导数按下面三条法则组合：

(uv)' = u'v + uv'
\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}
\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}u} \cdot \frac{\mathrm{d}u}{\mathrm{d}x}

叫链式法则。例如 y = \sin(x^2)，令 u = x^2，就有 y' = \cos(x^2) \cdot 2x。

链式法则像一组咬合的齿轮：y 相对 u 的转速，乘以 u 相对 x 的转速，就是 y 相对 x 的转速。

自变量不止一个时，把每个分量对每个自变量的偏导数排成矩阵，就得到雅可比矩阵。对 F(x, y) = (x^2 y,\; x + y)：

J = \begin{pmatrix} \dfrac{\partial F_1}{\partial x} & \dfrac{\partial F_1}{\partial y} \\[1.5ex] \dfrac{\partial F_2}{\partial x} & \dfrac{\partial F_2}{\partial y} \end{pmatrix} = \begin{pmatrix} 2xy & x^2 \\ 1 & 1 \end{pmatrix}

练一练

设 f(x) = x^3，求 f'(2) 的值。

幂法则：(x^n)' = n x^{n-1}。

f'(x) = 3x^2，所以 f'(2) = 12。

设 f(x) = x e^x，求 f'(0) 的值。

由，f'(x) = e^x + x e^x，代入 x = 0 得 1。

下面哪些等式成立？

  1. (\sin 2x)' = 2\cos 2x
  2. (x \ln x)' = \ln x
  3. \left(\dfrac{1}{x}\right)' = -\dfrac{1}{x^2}

第二个漏了一项：由乘积法则，(x \ln x)' = \ln x + 1。

本讲小结

  • 导数是差商的极限，几何上是切线的斜率。
  • 基本函数的导数查表，组合起来用乘积、商与链式法则。
  • 求导把“变化”变成了可以计算的对象。

把求导倒过来做，从变化率求总量，就是的主题。
