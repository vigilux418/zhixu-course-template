无限接近，却不必到达

导数与积分都建立在同一个想法上：当自变量无限接近某个值时，函数值会靠近谁。这一讲先用数值和图像建立直觉，再把它写成严格的定义。

  • 用数值与图像判断极限
  • 读懂极限的 ε–δ 定义
  • 用运算法则和重要极限求值

一个算不出来的点

函数 f(x) = \dfrac{x^2 - 1}{x - 1} 在 x = 1 处没有定义，因为分母为零。可是只要 x \ne 1，它就等于 x + 1。让 x 从两侧靠近 1，函数值列在里，图像见。

函数值与 2 的距离可以任意小，尽管永远取不到 2。我们把这件事记作

\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = 2

读作“当 x 趋于 1 时，f(x) 的极限是 2”。极限只关心靠近的过程，不关心 x = 1 这一点本身。

把“无限接近”说严格

“无限接近”是直觉，还不是定义。严格的说法柯西给出了雏形，魏尔斯特拉斯在 19 世纪 60 年代把它写成今天的样子。是：如果对任意给定的 \varepsilon \gt 0，总能找到 \delta \gt 0，使得

0 \lt |x - a| \lt \delta \implies |f(x) - L| \lt \varepsilon

就说 \lim_{x \to a} f(x) = L。对上面的例子，|f(x) - 2| = |x - 1|，取 \delta = \varepsilon 就满足，这正是第三列的规律。

极限也可能不存在。看分段函数

g(x) = \begin{cases} x + 1, & x \lt 0 \\ x^2, & x \ge 0 \end{cases}

它在 x = 0 两侧走向不同的值。只从一侧靠近时的极限叫单侧极限：左极限 \lim_{x \to 0^-} g(x) = 1，右极限 \lim_{x \to 0^+} g(x) = 0。两者不相等，所以 \lim_{x \to 0} g(x) 不存在。

反过来，如果极限存在，而且恰好等于函数值，即 \lim_{x \to a} f(x) = f(a)，就说 f 在 a 处连续。多项式、正弦函数、指数函数在定义域内处处连续，求它们的极限时直接代入即可。

运算法则与重要极限

设在同一个趋近过程中 \lim f(x) = A，\lim g(x) = B，则

\begin{aligned} \lim\,[f(x) \pm g(x)] &= A \pm B, \\ \lim\,[f(x)\,g(x)] &= AB, \\ \lim \frac{f(x)}{g(x)} &= \frac{A}{B} \quad (B \ne 0). \end{aligned}

另有两个极限要记住，后两讲会反复用到第二个极限给出了自然常数 e，这个记号出自欧拉。：

\lim_{x \to 0} \frac{\sin x}{x} = 1
\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^{n} = e \approx 2.718

求 \displaystyle \lim_{x \to 2} \frac{x^2 - 4}{x - 2}。

解答

直接代入得到 \frac{0}{0}，没有意义。先因式分解，再约去公因式：

\begin{aligned} \lim_{x \to 2} \frac{x^2 - 4}{x - 2} &= \lim_{x \to 2} \frac{(x - 2)(x + 2)}{x - 2} \\ &= \lim_{x \to 2}\,(x + 2) = 4. \end{aligned}

\frac{0}{0} 既不等于 0，也不等于 1，它只说明需要先变形。约分的前提是 x \ne 2，而极限恰好不看 x = 2 这一点。

练一练

求 \displaystyle \lim_{x \to 3} \frac{x^2 - 9}{x - 3} 的值。

分子可以分解成 (x - 3)(x + 3)。

约去 x - 3，得 \lim_{x \to 3}\,(x + 3) = 6。

利用，求 \displaystyle \lim_{x \to 0} \frac{\sin 3x}{x} 的值。

\dfrac{\sin 3x}{x} = 3 \cdot \dfrac{\sin 3x}{3x}，后一个因子趋于 1，所以极限是 3。

对里的 g(x)，下面哪个说法正确？

  1. \lim_{x \to 0} g(x) = 0
  2. \lim_{x \to 0} g(x) 不存在
  3. \lim_{x \to 0} g(x) = 1

左极限是 1，右极限是 0，两者不相等，极限不存在。

本讲小结

  • 极限描述趋近的过程，与函数在该点有没有定义无关。
  • \varepsilon–\delta 定义把“无限接近”变成可以验证的不等式。
  • 左、右极限都存在且相等，极限才存在。

有了极限，就能谈“一瞬间”的变化率，见。
