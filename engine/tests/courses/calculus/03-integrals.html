把无穷多个小块加起来

曲线下方的面积怎么算？把它切成许多细长的矩形，逐个相加；矩形越细，结果越准。让矩形的宽度趋于零，这个和的极限就是定积分。

  • 把定积分理解为黎曼和的极限
  • 用微积分基本定理计算定积分
  • 看出求导与积分互为逆运算

面积是和的极限

把区间 [a, b] 等分成 n 份，每份宽 \Delta x = \frac{b - a}{n}；在第 i 份上取一点 x_i，用高为 f(x_i) 的矩形近似这一小条的面积（）。这些矩形面积的总和叫黎曼和。当 n \to \infty 时，它的极限就是 f 在 [a, b] 上的定积分：

\int_a^b f(x)\,\mathrm{d}x = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i)\,\Delta x

积分号 \int 是一个拉长的字母 S莱布尼茨取自拉丁文 summa（求和）的首字母。，提醒我们积分本质上是求和；这里的极限仍按的方式理解。对 f(x) = x^2 和区间 [0, 1]，取右端点 x_i = \frac{i}{n}：

\begin{aligned} \sum_{i=1}^{n} \left(\frac{i}{n}\right)^{2} \cdot \frac{1}{n} &= \frac{1}{n^3} \sum_{i=1}^{n} i^2 = \frac{1}{n^3} \cdot \frac{n(n + 1)(2n + 1)}{6} \\ &= \frac{(n + 1)(2n + 1)}{6n^2} \;\longrightarrow\; \frac{1}{3} \quad (n \to \infty). \end{aligned}

改取每一份的左端点或中点，有限项的和会略有不同，但 n \to \infty 时极限仍是 \frac{1}{3}：极限与取点方式无关，正是“可积”的含义。

微积分基本定理

每次都算和的极限太辛苦。如果 F'(x) = f(x)，就称 F 是 f 的一个原函数。牛顿与莱布尼茨各自发现：

\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a)

直观的理由是：把积分上限看作变量，面积随上限增长的速度，恰好是曲线在那一点的高度，

\frac{\mathrm{d}}{\mathrm{d}x} \int_a^x f(t)\,\mathrm{d}t = f(x)

也就是说，面积函数本身就是 f 的一个原函数。

把求面积变成了求导的逆运算，于是倒过来读，就是一张积分表。由 (x^3)' = 3x^2 可知 \frac{x^3}{3} 是 x^2 的原函数，所以

\int_0^1 x^2\,\mathrm{d}x = \frac{x^3}{3}\,\Bigg|_0^1 = \frac{1}{3}

与上一节用算出的结果一致。把乘积法则（）两边积分，还能得到分部积分公式：

\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u

求 \displaystyle \int_0^{\pi} \sin x\,\mathrm{d}x。

解答

因为 (-\cos x)' = \sin x，由：

\int_0^{\pi} \sin x\,\mathrm{d}x = -\cos x\,\Big|_0^{\pi} = -\cos\pi + \cos 0 = 2

不定积分别忘了积分常数：\int 2x\,\mathrm{d}x = x^2 + C。定积分里，常数在 F(b) - F(a) 中相互抵消，可以不写。

练一练

求 \displaystyle \int_0^2 3x^2\,\mathrm{d}x 的值。

3x^2 的一个原函数是 x^3，所以结果是 2^3 - 0^3 = 8。

求 \displaystyle \int_1^{e} \frac{1}{x}\,\mathrm{d}x 的值。

想一想：谁的导数是 \frac{1}{x}？

\ln x\,\Big|_1^{e} = \ln e - \ln 1 = 1。

里五个矩形的面积之和是多少？请写成小数。

\frac{1}{5}\left(0.2^2 + 0.4^2 + 0.6^2 + 0.8^2 + 1^2\right) = 0.44。它比精确值 \frac{1}{3} 大，因为取右端点时矩形高出了曲线。

本讲小结

  • 定积分是黎曼和的极限，几何上是曲线下方的面积。
  • 微积分基本定理：定积分等于原函数在两个端点处的差。
  • 求导与积分互为逆运算，求导法则倒过来就是积分法则。
